Web page to PDF

Give a page's address and get its PDF, printed by Weblitz: its CSS laid out, its scripts run, its print styles applied. No browser runs on this server.

More settings

    As an API

    curl -o page.pdf "…/pdf?url=https://example.com"
    POST /pdf
Content-Type: application/json

{ "url": "https://example.com", "format": "Letter", "landscape": true, "hide": ["nav", "footer"] }

    GET /info?url=… answers what a print says of itself (pages, time, notes) as JSON. The settings are Puppeteer's page.pdf() options under the same names. Only public pages are printed.
